# Manifest schema (JSONL)

One JSON object per line. All paths in `image_path` may be relative to the NoFUD repo root.

## Required

```json
{
  "id": "fndds-001",
  "modality": "text",
  "source": "fndds_seed",
  "calories": 248,
  "protein_g": 46.5,
  "carbs_g": 0.0,
  "fat_g": 5.4
}
```

## Text sample

```json
{
  "id": "fndds-001",
  "modality": "text",
  "source": "fndds_seed",
  "text": "Chicken breast, roasted, 150 g",
  "calories": 248,
  "protein_g": 46.5,
  "carbs_g": 0.0,
  "fat_g": 5.4,
  "mass_g": 150,

```

## Image + user description (same modality, `text` set)

Prompt builders use `text` as the optional user note (matches app `analyzeFood(description=…)`). `meal_name` is metadata only and is not injected unless copied into `text`.

| Level | Manifest | `text` field |
|-------|----------|--------------|
| L0 | `jfb.jsonl` | absent — image only |
| L1 | `jfb_image_text_l1.jsonl` | `meal_name` (short title) |
| L2 | `jfb_image_text_l2.jsonl` | comma-joined ingredient names (no qty/macros) |

```json
{
  "id": "jfb-fsb_00000",
  "modality": "image",
  "source": "jfb",
  "text": "Breakfast Platter",
  "image_path": "benchmarks/food_accuracy/data/jfb/food-scan-benchmark-dataset/fsb_images/fsb_00000.jpg",
  "meal_name": "Breakfast Platter",
  "calories": 408.5,
  "protein_g": 30.1,
  "carbs_g": 33.5,
  "fat_g": 17.3
}
```

## Eval split files

- `eval_text.jsonl` — fixed 40-item text subset for prompt A/B (checked in).
- `data/manifests/jfb.jsonl` — L0 image-only JFB split (generated by `download_jfb.py`).
- `data/manifests/jfb_image_text_l1.jsonl` — L1 meal-name descriptions (generated by `download_jfb.py`).
- `data/manifests/jfb_image_text_l2.jsonl` — L2 ingredient-name descriptions (generated by `download_jfb.py`).
- `data/manifests/n5k.jsonl` — generated by `download_nutrition5k.py`.

# AI usage policy

## Development

Chompass is developed by me, 'fitguy'. English is not my first language, so
LLM assistants are used as a writing aid: wording, translations for the 18
app locales, and boilerplate, small refactorings, code generation,
development structure, etc. Every change is read, tested, and committed by
the maintainer (on the maintainer's hardware) before it lands. Commits are
authored as the maintainer and an unreviewed generated change is treated as
a defect.

## History

Chompass forked [Fud AI](https://github.com/apoorvdarshan/fud-ai) (MIT) on
2026-07-07. Fud AI is itself a (suspected) heavily AI-assisted project, and
the oldest Chompass commits, including third-party co-author trailers from
the July 2026 fork-bootstrap weeks, predate this policy and reflect that
starting point. Since the policy took effect on 2026-07-27, every commit is
maintainer-authored.

## In the app

This policy is about development. The AI features in the product are opt-in:
bring your own cloud API key, or run models on-device. All AI features can be
turned off while barcode, search, and manual logging keep working. See the
[AI section](../README.md#ai) and [`docs/PRIVACY.md`](PRIVACY.md).
